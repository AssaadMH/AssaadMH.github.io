# Bundled fonts

These two typefaces are **not my work**. They are redistributed here under the
SIL Open Font License 1.1, which permits bundling provided the licence travels
with the files — hence the two `LICENSE-*.txt` beside them.

| Font | Author | Licence |
|---|---|---|
| Inter | The Inter Project Authors (Rasmus Andersson) | OFL 1.1 — `LICENSE-Inter.txt` |
| JetBrains Mono | The JetBrains Mono Project Authors | OFL 1.1 — `LICENSE-JetBrainsMono.txt` |

They are self-hosted rather than loaded from a CDN so the site works offline and
prints to PDF correctly, and so it makes no third-party requests.
